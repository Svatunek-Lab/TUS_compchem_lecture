# 7 · Transition state

Find the transition state (TS) of the classic Diels–Alder reaction, butadiene +
ethylene → cyclohexene, and confirm it with a frequency calculation.

!!! tip "First time running ORCA?"
    See [Running ORCA](../orca.md) for how to run an input file from the command line.
    `/path/to/orca` below is the full path to your ORCA program.

A **transition state** is the highest point on the lowest-energy path between reactant
and product: a maximum along the reaction coordinate, but a minimum in all other
directions (a saddle point). Its energy relative to the reactants is the **activation
energy**, which determines how fast the reaction is.

A normal optimisation ([Exercise 2](02-opt.md)) always goes downhill and ends in a
minimum. A TS optimisation instead goes **uphill** along one direction and downhill along
all others. This only works if the start structure is already close to the TS, so the
most important step is a good guess.

## Step 1 · Build a TS guess

In the lecture we draw a guess structure together. For the Diels–Alder reaction:

- Butadiene in the **s-cis** conformation, with ethylene stacked on top of the two
  terminal carbons (C1 and C4 of the diene).
- The two **forming C–C bonds** about 2.0–2.2 Å long, both the same length (the
  reaction is concerted and synchronous). A normal C–C bond is 1.5 Å.
- The rest of the structure roughly like the product, cyclohexene, in a boat-like shape.

A scan along the forming bond ([Exercise 1](01-sp-scan.md)) is another way to get a
guess: the highest point of the scan is a good start structure.

| --------------- | ------- |
| `HF-3c` | Fast method (as for aspirin in [Exercise 2](02-opt.md)); no basis set needed |
| `OptTS` | Transition state optimisation instead of a normal optimisation |
| `Freq` | Frequency calculation at the end, to check the result |
| `Calc_Hess true` | Calculate the exact Hessian (second derivatives) at the start. The optimiser uses it to find the direction to go uphill |

```bash
/path/to/orca ts_opt.inp > ts_opt.out
```

This takes about 35 seconds on one core. With `PAL4` on the keyword line it runs on
4 cores; see [Cores and memory](../orca.md#cores-and-memory).

## Step 3 · Check the result

A TS optimisation that converged is not automatically the TS you want. Check two things.

**1. Exactly one imaginary frequency.** Search `ts_opt.out` for
`VIBRATIONAL FREQUENCIES` and take the **last** occurrence. Imaginary frequencies are
printed as negative numbers and marked `***imaginary mode***`.

| Imaginary frequencies | Meaning |
| --------------------- | ------- |
| 0 | A minimum, not a TS. The optimisation fell down to the reactant or product |
| 1 | A transition state |
| 2 or more | A higher-order saddle point. Not a TS; improve the guess |

The output contains two frequency calculations. The first is the Hessian of the
**start structure** (`Calc_Hess`), the second the final check at the **optimised TS**:

=== "Start structure (guess)"

    ```text
         6:    -476.12 cm**-1  ***imaginary mode***
         7:    -192.64 cm**-1  ***imaginary mode***
         8:      89.57 cm**-1
    ```

    Two imaginary frequencies: the guess is not yet a TS. That is normal for a guess.
    The optimiser follows the mode that looks like the reaction (`TS mode is mode
    number 0`) uphill and the other one downhill.

=== "Optimised TS"

    ```text
         6:    -925.97 cm**-1  ***imaginary mode***
         7:     181.20 cm**-1
    ```

    Exactly one imaginary frequency: a transition state.

**2. The imaginary mode is your reaction.** Open `ts_opt.out` in a viewer such as
[Avogadro](https://www.openchemistry.org/projects/avogadro2/) or
[Chemcraft](https://www.chemcraftprog.com) and animate the imaginary frequency. The two
forming C–C bonds should shorten and lengthen **together**: towards cyclohexene in one
direction, towards butadiene + ethylene in the other. If something else moves, it is
the TS of a different process.

### The TS structure

The optimisation converged after 25 cycles. The C–C bond lengths (Å) along the way:

| Bond | Guess | TS | Butadiene / ethylene | Cyclohexene |
| ---- | ----- | -- | -------------------- | ----------- |
| forming (C0–C2, C1–C5) | 1.95 | **2.18** | – | 1.5 |
| ethylene C=C (C0–C1) | 1.50 | 1.38 | 1.33 | 1.5 |
| diene C1=C2 (C2–C8, C5–C9) | 1.50 | 1.37 | 1.34 | 1.5 |
| diene C2–C3 (C8–C9) | 1.54 | 1.41 | 1.47 | 1.34 |

In the TS every bond is **in between** reactant and product: the double bonds have
started to lengthen, the central diene bond has started to shorten into the new double
bond, and both forming bonds have the same length (synchronous). (The reactant and
product values are typical bond lengths, for orientation.)

| File / section | Contents |
| -------------- | -------- |
| `THE OPTIMIZATION HAS CONVERGED` | The TS optimisation converged |
| `FINAL SINGLE POINT ENERGY` (last one) | Energy of the TS: −231.371464 E<sub>h</sub> |
| `VIBRATIONAL FREQUENCIES` (last one) | Exactly one negative frequency |
| `ts_opt.xyz` | The TS structure |

## Activation energy

The activation energy is the energy difference between the TS and the reactants:

$$
\Delta E^\ddagger = E_\text{TS} - \left(E_\text{butadiene} + E_\text{ethylene}\right)
$$

All three must be calculated with the same method. Optimise butadiene (s-trans, its most
stable conformer) and ethylene separately with `! HF-3c Opt Freq`
([Exercise 5](05-freq.md)), then take the difference of the `FINAL SINGLE POINT ENERGY`
values (1 E<sub>h</sub> = 627.5 kcal/mol). With `Final Gibbs free energy` instead you
get the free energy of activation ΔG<sup>‡</sup>.

!!! note
    HF-3c is fast but not accurate for barriers. For a reliable activation energy,
    re-optimise the TS and the reactants with DFT (e.g. `! B3LYP D3BJ def2-SVP`).
    The HF-3c TS is a good start structure for that.

??? info "Going further: IRC"
    An IRC (intrinsic reaction coordinate) calculation follows the imaginary mode
    downhill in both directions and shows which reactant and product the TS connects.
    Use the `IRC` keyword with the optimised TS structure and its Hessian.
    See [IRC (tutorial)](https://www.faccts.de/docs/orca/6.1/tutorials/react/irc.html).
